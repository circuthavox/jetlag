Challenge Editor

Manage the standalone challenge cards used by Jet Lag: The Game.

Open this editor from your local repository

This editor is deliberately disabled on GitHub Pages and when opened from the GitHub website. It must be served from a local copy of the repository.

From the repository root, run:

python3 -m http.server 8000

Then open http://localhost:8000/edit.html.

Local-only editor. When you finish, download the updated challenges.js and replace the existing file in your repository. The browser cannot silently overwrite repository files.
